# City Diff PDF portfolio reference

## Files

- `City-Diff-Portfolio-Reference.pdf` — 12-page, English-language, 16:9 reference PDF.
- `city-diff-portfolio.html` — editable source used to produce the PDF.
- `assets/portfolio-contact-sheet.jpg` — one-image overview of all pages.
- `assets/` — interface captures and research charts used by the layout.

## Editing

Open `city-diff-portfolio.html` in a browser to review changes. The layout uses fixed 16:9 pages and has no external font or image dependencies.

To export manually in Chrome:

1. Open the HTML file.
2. Choose **Print → Save as PDF**.
3. Enable **Background graphics**.
4. Use the CSS page size and set margins to **None**.

The current version is structured as a standalone project case study. For a larger application portfolio, pages 4–11 can be reduced to four spreads while preserving pages 1–3 and 12 as the narrative frame.
