05 · Computational method

Turn morphological intuition into geometric rules that can be challenged

The algorithm does not judge the city. It narrows 4,800 walking-network segments into sites worth checking against historical maps.

The output is deliberately named a morphology candidate rather than a “lost alley.” The label must leave room for the hypothesis to be disproved.

01Build the network graph

Merge nearby nodes using an 8 m tolerance.

02Find endpoints

Keep degree-one nodes away from the study boundary.

03Measure distance

Require endpoints to be 3–55 m from the selected road.

04Compare direction

Require cosine alignment toward the road ≥ 0.35.

05Remove duplicates

Within 12 m, retain only the stronger alignment score.

06Send to human review

Check whether a connection is visible in historical and current records.

4,800 network segments→ 379unique endpoint sites

07 · Sensitivity audit

Parameters are spatial positions taken by the researcher

Forty-eight parameter combinations test node tolerance, search distance, and alignment thresholds, exposing how unstable the output can be.

27
—270

A tenfold candidate range across the same roads

Search distance has the largest effect. Fifty-five metres is not objective truth; it defines the scale at which the system interprets a site as related to a road.

No ground truth → robustness, not accuracy.

This is not an accuracy test. It measures sensitivity to research choices and requires the interface to disclose them.

The algorithm narrows the search; people interpret and leave an accountable record

Conclusion · design position

Detected is not the same as proven.
Urban computation should reveal what still needs to be negotiated.

WHAT I BUILT

An operational urban evidence interface

Integrates historical maps, present-day networks, cultural heritage, candidate algorithms, human review, and a multi-city Explorer.

WHAT I LEARNED

Uncertainty must be designed

Parameters, data gaps, and zero results must remain visible; otherwise a polished interface only amplifies false certainty.

WHAT COMES NEXT

From geometric candidates to fieldwork and governance

The next phase requires vector cadastral data, field observation, local knowledge, access rights, and governance processes.
